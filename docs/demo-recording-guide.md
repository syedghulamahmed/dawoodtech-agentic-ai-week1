# Demo recording guide

1. Open a terminal in the repository and ensure the .env file is not visible on screen.
2. Start the assistant with uv run agentic-assistant.
3. Ask for a calculator operation and show the assistant selecting and executing calculate.
4. Ask it to save a SQLite note, then search for that note.
5. Show the validated JSON output, including answer, tools_used, and confidence.
6. Keep API keys, environment files, private notes, and personal data out of the recording.

Do not use the offline demo command as evidence of live model inference. It uses a deterministic mock provider.
